# Gymdesk Retention Copilot

A functional product concept created as an application artifact for a Product Manager role at Gymdesk.

## Product hypothesis

Gymdesk already surfaces meaningful retention signals such as changes in attendance. This prototype explores the next step: **signal → context → appropriate action**.

The AI is deliberately positioned as a copilot rather than an autonomous churn predictor. It explains observable signals, distinguishes known information from assumptions, recommends a next action, drafts communication, and requires human approval before outreach.

## Demo flow

Retention Overview → Member Detail → AI Insight → Recommended Action → Editable Message → Confirmation

## Success metrics

**Primary:** intervention rate.

**Secondary:** time from signal to action, recommendation acceptance/edit rate, member return rate, retention after intervention, and staff adoption.

**Guardrails:** irrelevant recommendations, staff dismissals, and messages requiring substantial edits.

## Scope

This is a front-end prototype using fictional demo data. It does not connect to Gymdesk systems or send real messages.
